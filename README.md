# Bitellova

Bitellova is an experimental Othello application for learning Swift.

The primary purpose of this project is to explore Swift programming by implementing an Othello game from the ground up. Rather than aiming at a production-ready game or a strong Othello engine, Bitellova is intended as a small experimental project for learning, experimentation, and research.

## Requirements

Bitellova requires an environment in which Swift can run and the `Foundation` framework can be imported.

## Project Status

Bitellova is currently in an early experimental stage.

The design and implementation may change substantially as development progresses and new ideas are explored.
